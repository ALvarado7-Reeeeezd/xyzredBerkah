Login Customer

Simpan data sekali, mudahkan checkout berkali-kali

Halaman ini bukan login seperti aplikasi perbankan. Data yang Anda isi hanya disimpan di browser Anda sendiri melalui localStorage, dan digunakan untuk memudahkan kami ketika menyusun pesanan di WhatsApp.

Anda bisa mengubah atau menghapus data ini kapan saja. Jika ganti perangkat atau browser, data perlu diisi ulang.

Informasi yang kami simpan:

  • Nama lengkap yang akan digunakan saat pengiriman.
  • Nomor WhatsApp utama untuk komunikasi pesanan.
  • Alamat singkat / patokan (opsional) sebagai pengingat.

Detail alamat lengkap dan preferensi pengiriman tetap dikonfirmasi di WhatsApp setiap kali order.

Login / Profil Customer

Isi data di bawah untuk menyimpan profil di perangkat ini.

Gunakan format angka tanpa spasi, misalnya 62812xxxxxxx.

Data ini tidak dikirim ke server mana pun, hanya tersimpan di browser Anda. Jika Anda membersihkan cache/storage, data akan ikut terhapus.
